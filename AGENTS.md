# Market Research Agent Project Instructions

This repository is for a reusable, standalone TypeScript CLI Market Research Agent.

Project rules:

- Keep the agent generic so any person can research any product, market, industry, or customer problem.
- Do not assume a particular company, founder, product, industry, or audience unless the user's research question names it.
- Keep the agent standalone.
- Use TypeScript and Node.js.
- Use the OpenAI SDK for analysis.
- Use Tavily for web search.
- Save reports locally as JSON and Markdown.
- Do not add a frontend, database, authentication, deployment, or multi-agent architecture unless requested.
- Keep instructions beginner-friendly.
- Explain every file changed.
